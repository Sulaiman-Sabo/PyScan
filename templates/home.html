PyScan at Glance

An in-depth guide explaining the background, artificial intelligence architecture, and security capabilities of PyScan.

1. Research Motivation & Problem Statement

Traditional Static Application Security Testing (SAST) tools, such as Bandit or Flake8, rely on rigid regular expressions and hardcoded AST rules. When developers use variable aliasing, string formatting, or indirect function calls (e.g. cmd = input(); fn = os.system; fn(cmd)), traditional SAST suffers high false negative rates (**up to 71.1% false negative rate**).

PyScan solves this problem by employing a deep learning neural network trained on over 15,197 real-world Python functions from CVEFixes and VUDENC. PyScan learns deep semantic patterns, achieving an **85.6% recall rate** (+56.7% recall improvement over traditional SAST).

2. The 5-Stage AST Preprocessing Pipeline

Stage 1: Code Cleaning

Strips comments, enforces 4-space indentation, standardizes quotes, and handles non-UTF8 encodings cleanly.

Stage 2: Function & Script Extraction

Extracts top-level def functions using Python AST. Top-level scripts without functions are processed as <module_main>.

Stage 3: Feature Anonymization

Masks user variable names (var1, var2) and string literals (STRING_LIT) while preserving built-in security sinks.

Stage 4: Tokenization & Tensor Padding

Converts code tokens into vocabulary index arrays from a master vocabulary of 15,095 tokens, padded to MAX_SEQ_LEN = 200.

Stage 5: BiLSTM-Attention Inference

Feeds vectorized matrices into a 2-layer BiLSTM model (128 embedding dim, 64 hidden dim) with a self-attention classification head.

3. Covered 11 CWE Vulnerability Categories

CWE-78OS Command Injection

Passing user input directly to os.system or exec.

CWE-89SQL Injection

Concatenating unsanitized strings into database queries.

CWE-502Insecure Deserialization

Deserializing untrusted data with pickle.loads or yaml.load.

CWE-798Hard-coded Credentials

Embedding API secret keys or passwords in source code.

CWE-327Insecure Cryptography

Using broken hash algorithms (MD5, SHA1, DES, RC4).

CWE-79Cross-Site Scripting (XSS)

Rendering unescaped HTML strings in web templates.

CWE-22Path Traversal

Reading files outside authorized directories via unvalidated paths.

CWE-918Server-Side Request Forgery

Fetching internal endpoints based on untrusted URL parameters.

CWE-330Weak Randomness

Using non-cryptographic PRNGs for tokens or secret nonces.
